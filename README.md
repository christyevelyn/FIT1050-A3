# The Secondhand Bookshop: Homepage Redesign

Homepage redesign based on a real Australian secondhand bookshop whose original website felt cluttered and outdated. The business name and contact details in this version are fictional.

The new design uses a cleaner, minimal layout, with ideas taken from other bookshop websites.

Live: https://christyevelyn.github.io/FIT1050-A3/

## Sections
- Header banner with a welcome message and shop opening hours
- New Arrivals gallery of recently added books
- Browse by Category with 15 expandable book categories
- Customer Reviews
- Footer with contact details and links

## Interactive Feature
Clicking a book cover in New Arrivals opens it in a lightbox gallery, so visitor can view covers at a larger size and move between books without leaving the page. Built with the Fancybox library.

## Design Work
- Rearranged and removed template sections to fit the bookshop's content
- New colour scheme and backgrounds
- Large call-to-action buttons at the end of each main section
- Adjusted layouts with HTML and CSS

Book titles, authors, and prices are placeholders.
